I)it can be run using nohup


 4. Run Spring Boot JAR with nohup
nohup java -jar demo.jar > output.log 2>&1 &


Explanation:
nohup: Prevents the app from stopping after logout


> output.log: Saves app logs


2>&1: Also saves error logs


&: Runs in background

==============
If you want to STOP the background process:

1. Find PID
ps -ef | grep EC2TUTORIAL

Example output:

ec2-user  31245  ... java -jar EC2TUTORIAL-0.0.1-SNAPSHOT.jar

Here 31245 is PID.

2. Kill the Process
kill -9 31245

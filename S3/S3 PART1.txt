key concepts
=============

1)Bucket ==> like a folder ,Top level container for you files(objects)

2)object ==> any file you upload(with metadata and key)

3)key  ==> unique name for object in bucket

4)region :Aws region where bucket resides

5)Storage classes:Differernet cost 

6)Public access :Controls who can access buckets or files
